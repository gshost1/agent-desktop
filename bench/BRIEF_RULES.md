# Rules every writer and probe brief carries (copy verbatim)

- Personal data: use only folders the bench creates under `~/agent-desktop-bench/` (`bench-*`, `probe-*`, `t3-*`). Never open, navigate to, list, snapshot, screenshot or read `~/Pictures`, `~/Documents`, `~/Desktop`, `~/Downloads`, `~/Movies`, `~/Music`, the home folder, Recents, iCloud Drive, Photos, Mail, Messages, or any of George's own apps, windows or files. A Finder window is always opened by explicit bench path.
- Go to Folder and path sheets: type or set-value a full bench path. Never snapshot, find or read inside the suggestion table. Never press Return while focus is in the suggestions; check that the path field holds focus right before the key. Verify navigation only by the bench window's title, and close any window that is not on a bench folder at once.
- Windows: find them by AX title with `/Users/Shost2/.t3/worktrees/agent-desktop/perf-speed-cost/bench/out/macctl`. Send a key only after checking that the target bench window is in front. A probe leaves 0 windows and 0 sheets behind: dismiss a sheet (raise, Escape) before closing its window, check by title that every probe window is gone, and exit nonzero if any is left. The speed session runs probes through `bench/probe_slot.sh`, whose hygiene check fails a probe that leaves anything.
- Writers never touch the desktop: no GUI, no `~/.agent-desktop/bench.lock`, no agent-desktop against real apps. They write a probe script plus a pinned release binary under `~/agent-desktop-bench/probe-<name>-<sha>/` for the speed session to run.
- Never AppleScript System Events. No TCC or System Settings changes. Never read secret files.
- Every cargo command goes through `bash /Users/Shost2/.t3/worktrees/agent-desktop/perf-speed-cost/bench/serial_cargo.sh <cargo cmd>`, one at a time; `cargo build --tests` and `cargo test` are separate calls. The pre-commit hook runs cargo: run it as `serial_cargo.sh bash .githooks/pre-commit`, then commit with `SKIP_PRECOMMIT=1`.
- Fork only (`--repo gshost1/agent-desktop`), draft PRs, never push to main, never force-push, nothing upstream. Grep PR bodies and commit messages for `@` and `vercel-labs` before posting. No AI attribution.
- Last line of the reply: `PR <full URL>, head <SHA>, checks and reviews <state>`, plus the probe command if there is one.

### Bug Fixes

* `-w` and `--wait-for-gone` after a ref action on a web ref now read the page over its DevTools endpoint instead of the browser window's native accessibility tree, where Chrome's page reads as incomplete. `press down --ref @field -w 'statictext:Honolulu'` on weather.gov used to time out every time and now returns in about 0.49 s; post-action observation after `delivery_uncertain` reads the page the same way, so browser UI outside it, such as a JavaScript dialog, needs `snapshot --surface window`. The web quickstart now teaches the suggestion-list wait in place of a `sleep`: on a three-run Sonnet weather task the median went from 10 to 8 turns and 23.9 s to 16.1 s, and total `sleep` from 13 s to 3 s. ([#NNN](https://github.com/gshost1/agent-desktop/pull/NNN))

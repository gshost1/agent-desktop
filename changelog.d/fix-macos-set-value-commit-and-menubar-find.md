### Bug Fixes

* macOS `set-value` on a plain text field now ends the edit with a focus round trip through another enabled plain text field in the same window and back, so the app commits the value at once; it returns `application_commit: "committed"` only when focus came back and the read-back matches exactly or with trailing decimal zeros, with the neighbouring values the commit changed, fails with `details.kind: "edit_focus_not_restored"` when focus did not come back, and fails with `ACTION_FAILED` when the app did not keep the value, or with `details.kind: "edit_commit_refused"` when the app would not let the edit end, as when it opens an alert rejecting the value.
* `find --surface menubar` no longer returns a `TIMEOUT` that more time cannot fix when part of the menubar cannot be read, such as a menubar Help menu's search field after a menu was opened: matches seen are listed with `complete: false`, and no match returns `ELEMENT_NOT_FOUND` with `details.kind: "locator_unreadable_part"`.
* An empty `find --surface menubar` answer carries `data.hint`, which says that closed menus are searched and that a pane or a window that is not open belongs to a window search.

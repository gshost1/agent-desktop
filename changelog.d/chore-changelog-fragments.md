### Documentation

* A pull request now adds its changelog entry as a fragment, `changelog.d/<branch>.md`, instead of editing `CHANGELOG.md`, so parallel pull requests no longer conflict at the top of the changelog. The release pull request runs `python3 scripts/changelog_fragments.py assemble --version <x.y.z>`, which writes the release section with its headings in order and every bullet byte for byte, and deletes the fragments. The pre-commit hook checks staged fragments and refuses a `CHANGELOG.md` edit outside a release, and `scripts/check-release-consistency.sh` checks every fragment and fails while the changelog's top section is not the workspace version. ([#NNN](https://github.com/gshost1/agent-desktop/pull/NNN))

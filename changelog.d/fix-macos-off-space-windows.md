### Bug Fixes

* macOS: `list-windows --app` lists an app's windows on another Space, with `visible: false`, `accessible: false` and `on_other_space: true`, instead of returning `[]`; `snapshot` and `find` on one fail `ACTION_NOT_SUPPORTED` `window_on_other_space` and name `focus-window`, which now activates the app so macOS switches to its Space and then raises the window; `screenshot --window-id` captures it in place, and `screenshot --app` picks among the windows `list-windows --app` shows instead of every off-screen window the process owns. The `WINDOW_NOT_FOUND` suggestion for an app with no matching window names `list-windows` and `focus-window` instead of only "wait for the app to present a window".
* An `AMBIGUOUS_TARGET` between windows no longer lists the candidates' titles, which in a browser are the user's open tabs; each candidate carries `id`, `is_focused`, `visible` and, when known, `on_other_space`. The macOS `verified_window_title_ambiguous` error names the window id instead of the title.

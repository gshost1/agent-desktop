### Bug Fixes

* On macOS, `set-value` on a text field or text area returns `delivered_unverified` with `details.application_commit: "unobserved"`, `verification_reason: "edit_commit_unobserved"` and a `commit_hint`, instead of `delivered_verified`. Many fields hand their text to the document only when editing ends, so the field read back the new value while Save wrote the old one: an Automator URL field, Automator action fields and Script Editor text in held-out runs. Run `focus` on another field in the same window to end the edit. `set-value` never confirms the field itself, because Return in a field can submit a form, run a search or send a message.
